# Python 复习路线

## 1. 基础语法

- 变量与基本类型：`int`、`float`、`str`、`bool`、`None`
- 条件判断：`if`、`elif`、`else`
- 循环：`for`、`while`、`break`、`continue`
- 输入输出：`input()`、`print()`、格式化字符串

## 2. 常用数据结构

- `list`: 有序、可变
- `tuple`: 有序、不可变
- `dict`: 键值对映射
- `set`: 去重、集合运算
- 切片、遍历、推导式

## 3. 函数

- 函数定义与返回值
- 位置参数、关键字参数、默认参数
- `*args` 与 `**kwargs`
- 作用域：局部变量、全局变量

## 4. 模块与文件

- `import` 的几种形式
- 常用标准库：`os`、`pathlib`、`json`、`datetime`、`collections`
- 文件读写：`open()` 与 `with`

## 5. 异常处理

- `try`、`except`、`else`、`finally`
- 常见异常类型
- 主动抛出异常：`raise`

## 6. 面向对象

- 类与对象
- 实例属性与类属性
- 实例方法、类方法、静态方法
- 继承、多态、特殊方法

## 7. 进阶语法

- 迭代器与生成器
- 装饰器
- 上下文管理器
- 类型注解
