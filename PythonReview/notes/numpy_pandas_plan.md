# NumPy 与 Pandas 复习计划

## NumPy

- 创建数组：`np.array`、`np.arange`、`np.linspace`、`np.zeros`、`np.ones`
- 数组属性：`shape`、`ndim`、`dtype`、`size`
- 索引与切片
- 布尔索引
- 广播机制
- 常用统计函数：`mean`、`sum`、`std`、`min`、`max`
- 向量化计算

## Pandas

- `Series` 与 `DataFrame`
- 读取数据：`read_csv`
- 查看数据：`head`、`info`、`describe`
- 选择行列：`loc`、`iloc`
- 缺失值处理
- 排序与筛选
- 分组聚合：`groupby`
- 合并数据：`merge`、`concat`
- 时间序列基础
