# Python / NumPy / Pandas Review

这个目录用于系统复习 Python，并在之后继续复习 NumPy 和 Pandas。

## 推荐顺序

1. Python 基础语法与数据结构
2. 函数、作用域、模块与包
3. 文件处理、异常处理、常用标准库
4. 面向对象编程
5. 迭代器、生成器、装饰器
6. NumPy：数组、索引、广播、向量化计算
7. Pandas：Series、DataFrame、清洗、分组、合并、时间序列

## 目录说明

- `notes/`: 复习笔记
- `exercises/`: 练习题和代码
- `datasets/`: 后续 Pandas 练习用数据集

## 学习方式

每一轮建议按这个节奏：

1. 先读对应笔记。
2. 自己完成练习，不急着看答案。
3. 把不熟的地方记录到 `notes/mistakes.md`。
4. 让我帮你批改、补充知识点或继续出题。
