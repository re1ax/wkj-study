# Algorithm Practice

这个目录用于系统练习算法题。

## 目录结构

- `problems/`: 每道题的解法、思路和复盘
- `templates/`: 常用代码模板
- `cpp/`: 使用 C++ 练习算法题
- `python/`: 使用 Python 练习算法题
- `notes/`: 算法专题笔记

## 建议练习节奏

1. 先独立思考 10-20 分钟，写出暴力解法或关键观察。
2. 再优化时间复杂度和空间复杂度。
3. 提交后记录错因、边界条件和更好的写法。
4. 每隔 3-7 天复习一次做错或卡住的题。

## 推荐专题顺序

1. 数组与字符串
2. 哈希表
3. 双指针与滑动窗口
4. 栈与队列
5. 二分查找
6. 链表
7. 树与递归
8. 回溯
9. 动态规划
10. 图论
